Install in three steps

01

Get the file

Download a finished skin above or export one from either builder.

02

Import it

In Reeltone, open Settings → Appearance → Import Skin.

03

Switch it on

Preview, install, and select it. On Mac, shaped designs appear in Skin Mode.

Reeltone skins are declarative packages, not executable plugins. Builders process files locally in your browser.
